# web101-labs

Weekly lab exercises for Web 101.

## Week 01 – Dev Tools & First HTML Page

**Goal:** Get comfortable with browser DevTools, VS Code, and a basic HTML file, and observe a real HTTP request.

**Files:**
- `hello.html` – A minimal HTML page opened directly in the browser.

## Steps Completed
1. Installed VS Code, Node.js, Git
2. Opened a news site → F12 → Network tab → reloaded
3. Identified: HTML doc, CSS file, JS file, image request
4. Clicked the HTML request → inspected request/response headers
5. Created `hello.html` in VS Code
6. Double-clicked to open in browser
7. Committed to this GitHub repo
